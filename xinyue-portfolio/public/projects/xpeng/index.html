独立公司研究

小鹏汽车：超越整车的价值

存量博弈中的结构红利与物理人工智能的技术兑现

PROJECT NOTES / THE BIG PICTURE

研究思路

内容导航
01

研究主线

+

行业发生了什么变化，为什么这些变化对小鹏相对有利，以及技术优势能否在现金约束下转化为持续利润与可归属的股东价值。

02

七章研究框架

+

宏观需求与结构迁移；价格带、利润池与技术路线；技术底座、产品矩阵与组织；全球化与欧洲本地化；整车、Robotaxi、机器人与飞行汽车；盈利修复与商业模式；关键假设、分部估值与风险边界。

03

财务与估值

+

以 2021—2025 年历史合并报表为基础，重点预测 2026—2028 年，并延伸至 2035 年稳态终值；使用相对估值、FCFF、FCFE 和分部估值交叉检验经营假设，区分业务价值、实际持股比例和未来稀释。

04

关键跟踪变量

+

技术授权客户接续、现金消耗、销量与产能利用率、自动驾驶监管、产品结构和新业务量产。报告中的估值是经营假设检验，并非正式目标价。
