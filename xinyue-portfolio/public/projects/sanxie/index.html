三协电机：回报背后的条件

LBO 模型、投资备忘录与动态情景分析

PROJECT NOTES / THE BIG PICTURE

研究思路

内容导航
01

案例交易与回报

+

案例假设以每股 13 元收购三协电机，完全稀释股数 103.33 百万股，股权购买价 1343.29 百万元，初始发起人股本 886.90 百万元，收购债务 413.00 百万元。进出场 EV/EBITDA 均为 14.91 倍。模型 IRR 为 28.63%，MOIC 为 3.40 倍。

02

经营质量与产业位置

+

分析 3D 打印、光伏跟踪、工业自动化、纺织、安防和机器人需求；将设备需求、单机电机价值量、供应份额与 ASP 联系起来，考察客户议价、原料价格、产品内毛利变化和应收质量。

03

现金流与追加资本

+

前三年需追加发起人股本 102.56 百万元，分别为 61.18、37.46 和 3.92 百万元。模型连接经营预测、债务摊还、最低现金、现金清扫、股本追加和退出价值；按完整股东现金流计算 IRR。

04

投资判断与敏感性

+

备忘录建议进入针对性尽调，在有约束力报价前验证融资与经营恢复。检验退出 EBITDA、毛利率、退出倍数、收入增速、进入溢价、资本开支及营运资金。EBITDA 增长占正向价值创造的 92.3%。数值为案例条件性测算，非实际投资业绩。
