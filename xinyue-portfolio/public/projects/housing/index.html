房价稳定性：数据与政策

房价稳定性，可以从哪些因素理解？

PROJECT NOTES / THE BIG PICTURE

研究思路

内容导航
01

核心判断

+

这项研究使用爬虫采集的数据与决策树等机器学习方法，从基本面和政策有效性两个角度研究房价稳定性，并构建预测模型。研究将城市治理中的实际问题转化为数据分析任务，尝试从多种因素之间的关系理解房价表现。论文入选 APNHR 论坛；预测模型描述的是数据中的关系，不能单凭预测结果认定政策具有因果效果。

02

分析过程

+

收集并组织与房价稳定性相关的数据。 结合基本面和政策因素构建决策树等预测模型。 将预测关系与政策因果效果区分，明确模型解释的范围。

03

论文与项目题名

+

《房价稳定性影响因素决策树模型：基于基本面和政策有效性的双重实证》
