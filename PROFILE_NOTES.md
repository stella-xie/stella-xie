# Stella Xie Profile README Notes

This repository powers the GitHub profile page for `stella-xie`.

## How it works

- The public repository must be named exactly `stella-xie`.
- `README.md` appears at the top of the GitHub profile.
- `.github/workflows/snake.yml` generates the contribution snake SVG on the `output` branch.
- The snake may take a few minutes to appear after the first workflow run.
